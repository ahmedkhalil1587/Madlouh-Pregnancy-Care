# تصدير قاعدة البيانات

المجلد يحتوي على نسخة من الجداول الموجودة وقت التصدير:

- `data.json`: نسخة JSON للنسخ الاحتياطي أو الاستعراض.
- `seed-data.sql`: بيانات قابلة للاستيراد بعد إنشاء مخطط الجداول.
- `../drizzle/`: ملفات إنشاء الجداول وتحديثاتها بالترتيب.

## ترتيب الاستيراد إلى Cloudflare D1

1. أنشئي قاعدة D1 جديدة في حساب Cloudflare.
2. طبّقي ملفي المخطط داخل `drizzle/` بالترتيب: `0000` ثم `0001`.
3. استوردي `seed-data.sql`.

لا تعيدي استيراد هذا الملف إلى قاعدة تحتوي على بيانات، لأنه يحتفظ بالمعرّفات نفسها.

هذه البيانات تتضمن معلومات صحية وشخصية؛ احتفظي بها في مكان خاص ولا تضعيها في مستودع GitHub عام.
