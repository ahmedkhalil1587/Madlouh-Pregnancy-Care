# بوابة إرسال OTP لمجمع المدلوح الطبي

## 1. رفع ملفات البوابة

ارفعي الملفين التاليين داخل `public_html/otp-api`:

- `send.php`
- `.htaccess`

## 2. وضع ملف الإعداد المحمي

1. غيّري اسم `otp-config.example.php` إلى `otp-config.php`.
2. من cPanel ضعيه في المجلد الرئيسي لحساب الاستضافة، **بجوار** `public_html` وليس داخله.
3. استخدمي مولد كلمات المرور في cPanel لإنشاء مفتاح عشوائي لا يقل عن 48 حرفًا.
4. افتحي `otp-config.php` واستبدلي النص `REPLACE_WITH_A_RANDOM_KEY_OF_AT_LEAST_48_CHARACTERS` بالمفتاح.
5. لا ترسلي المفتاح أو كلمة مرور البريد في المحادثة.

سيبقى المرسل هو `noran.aldalli@madlouh.com.sa`. لا يحتاج هذا الملف إلى كلمة مرور البريد لأنه يستخدم خدمة إرسال البريد المحلية في الاستضافة.

## 3. اختبار الوصول

افتحي في المتصفح:

`https://madlouh.com.sa/otp-api/send.php`

النتيجة الصحيحة عند الفتح العادي هي رسالة JSON تقول `POST requests only`. هذا يعني أن الملف يعمل ويرفض الاستخدام المباشر.

بعد ظهور هذه الرسالة، ارجعي للمحادثة واكتبي: **تم الرفع وظهر POST requests only**. عندها نربط البوابة بموقع متابعة الحمل ونضيف مدير IT وحسابات الأطباء.

## ملاحظات أمنية

- لا تضعي `otp-config.php` داخل `public_html`.
- لا تشاركي مفتاح API مع أي شخص.
- البوابة تقبل الإرسال فقط إلى عناوين تنتهي بـ `@madlouh.com.sa`.
- يوجد حد زمني يمنع إرسال أكثر من رسالة إلى العنوان نفسه خلال دقيقة.
- يجب أن يكون HTTPS فعالًا على `madlouh.com.sa`.
